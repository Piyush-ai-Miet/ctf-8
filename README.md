# CTF-8 Repository

This repository contains the SANITY_CHECK challenge for CTF-8.

## Challenge Overview

**Challenge Name**: SANITY_CHECK  
**Points**: 10  
**Difficulty**: Beginner  

## Objective

Find the flag by following the provided instructions.

## Files

- `ctf 8` - Original challenge description
- `SOLUTION.md` - Detailed solution guide
- `find_flag.sh` - Script that explains the flag-finding process

## Quick Start

1. Read the challenge description in the `ctf 8` file
2. Follow the instructions to join the Discord server
3. Search for the flag within the server
4. Run `./find_flag.sh` for guidance if needed

## Flag Location

The flag is located in the Discord server (not in this repository). This is a sanity check challenge designed to test basic instruction-following capabilities.

**Discord Server**: https://discord.gg/yvHCMA4V
